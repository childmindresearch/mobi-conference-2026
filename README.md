## 🌐 Overview

CMI's Multimodal Brain-Body Imaging (MoBI) Laboratory integrates electrophysiological recordings (EEG, physio) with motion capture (MoCap), eye-tracking, and behavioral metrics to study human brain function in dynamic environments. This repository provides:
- **Open-source software tools** for real-time visualization, quality control, and data acquisition.
- **Abstracts & posters** presented at the 6th International Mobile Brain/Body Imaging Conference.
- **Direct links to individual tool repositories** for installation, usage guides, and source code.

## 🛠️ Software Tools & Repositories

### 1. **MoBI-View: Realtime Biosignal Visualization**
- **Repository**: [github.com/childmindresearch/Mobi-View)](https://github.com/childmindresearch/MoBI-View)
- **Description**: An open-source visualization tool tailored for Lab Streaming Layer (LSL) streams, allowing researchers to monitor EEG, kinematic, and physiological signals in real time.
- **Files**: [Abstract (PDF)](./abstracts/mobi_view_lsl_abstract.pdf) | [Poster (PDF)](./posters/mobi_view_lsl_poster.pdf)

---

### 2. **Multimodal Brain-Body Automated QC Framework**
- **Repository**: [github.com/your-org/mobi-qc-framework](https://github.com/your-org/mobi-qc-framework)
- **Description**: A scalable software framework that automates data quality assurance from live data acquisition to post-session reporting in multimodal setups.
- **Files**: [Abstract (PDF)](./abstracts/acquisition_to_assurance_qc_abstract.pdf) | [Poster (PDF)](./posters/acquisition_to_assurance_qc_poster.pdf)

---

### 3. **Realtime Motion Capture QC Mechanism**
- **Repository**: [github.com/your-org/mocap-qc](https://github.com/your-org/mocap-qc)
- **Description**: Dedicated automated quality control mechanism that processes optical and sensor-based MoCap data in real-time to detect marker loss, tracking artifacts, and subject movement boundaries.
- **Files**: [Abstract (PDF)](./abstracts/realtime_mocap_qc_abstract.pdf) | [Poster (PDF)](./posters/realtime_mocap_qc_poster.pdf)

---

### 4. **CAMI Study Replication Toolkit (Pediatric Neurodivergent Population)**
- **Repository**: [github.com/your-org/cami-pediatric-study](https://github.com/your-org/cami-pediatric-study)
- **Description**: Software tools and data analysis pipeline for replicating the Computerised Assessment of Motion Imitation (CAMI) protocol tailored for neurodivergent pediatric cohorts.
- **Files**: [Abstract (PDF)](./abstracts/cami_study_replication_abstract.pdf) | [Poster (PDF)](./posters/cami_study_replication_poster.pdf)

---
